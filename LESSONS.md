# Lessons for KOML

Shadow comparison needs a precise rule, an actual recorded choice, and an explicit cutoff. A disagreement is a difference, not proof that either decision was wrong. This build makes that distinction visible.

The assumption that local deterministic comparisons can reconcile exactly was validated on four independently specified groups of 50 synthetic records. Altering an actual choice changes the disagreement count by one; the engine does not consume the expectations file. Synthetic evidence does not validate usefulness to Henry or decision quality.

One operating rule for future builds: retain each computed choice beside its source file and line, and test altered ground truth before accepting aggregate figures. Aggregate-only output can hide dropped or duplicated records.

The observed Windows user-install launcher was outside PATH. The documented virtual-environment setup and module fallback address that concrete setup issue. This is build feedback, not a substitute for the two-week real-use improvement hook.
